# Activity 9: Setup Power BI

**Objective:** Install Microsoft Power BI Desktop to build interactive reports and data models.

## Important Note for macOS/Linux Users
**Power BI Desktop is currently only available for Windows.** 
If you are using a Mac or Linux machine, you have a few options:
1. Use **Boot Camp** (on Intel Macs) or virtualization software like **Parallels Desktop** or **VMware Fusion** to run Windows.
2. Use the **Power BI Service** in your web browser (has limited data modeling features compared to Desktop).
3. Use a lab computer provided by the university if required for an assignment.

## Step 1: Download and Install (Windows)

There are two ways to install Power BI Desktop on Windows. Using the Microsoft Store is generally recommended as it handles updates automatically.

**Option A: Microsoft Store (Recommended)**
1. Open the **Microsoft Store** app on your Windows PC.
2. Search for **Power BI Desktop**.
3. Click **Get** or **Install**.

**Option B: Direct Download**
1. Go to the [Power BI Desktop download page](https://powerbi.microsoft.com/desktop/).
2. Click **Download** or **Advanced download options** to get the `.exe` installer.
3. Run the installer and follow the setup wizard.

## Step 2: Sign In

While you can use Power BI Desktop without an account, signing in allows you to publish and share your reports.

1. Launch Power BI Desktop.
2. On the welcome screen, click **Sign In**.
3. Use your university Microsoft 365 account credentials (typically your `.edu.au` email address) to sign in.

## Step 3: Verify Installation
Once Power BI is open, you should see a blank canvas in the center, a "Visualizations" pane on the right, and a "Data" pane. If you see this interface, Power BI is successfully installed and ready for data importing.
