# Activity 5: Setup AI Coding Agents

**Objective:** Install and configure AI coding assistants to help you write, debug, and understand code throughout this course. 

We will focus on two powerful tools: **GitHub Copilot** (an extension for VS Code) and **Cursor** (a standalone IDE built for AI).

---

## Option A: GitHub Copilot (for VS Code)

GitHub Copilot provides intelligent autocomplete suggestions directly inside Visual Studio Code.

1. **Get the Student Pack:** Go to the [GitHub Education](https://education.github.com/pack) page. Apply for the Student Developer Pack using your `.edu.au` email address to get GitHub Copilot for free.
2. **Install the Extension:** 
   - Open VS Code.
   - Go to Extensions (`Ctrl+Shift+X` / `Cmd+Shift+X`).
   - Search for **GitHub Copilot** and install it.
3. **Authenticate:** Click the Copilot icon in the bottom right corner of VS Code and sign in with your GitHub account (the one with the approved Student Pack).

---

## Option B: Cursor IDE

Cursor is a fork of VS Code that has AI deeply integrated, allowing for multi-file edits, codebase chat, and more. It is free for students.

1. **Download Cursor:** Go to [cursor.com](https://www.cursor.com/) and download the installer for your OS.
2. **Install and Launch:** Run the installer. Since it is based on VS Code, it will feel very familiar.
3. **Sign Up:** Create a Cursor account. **Important:** Use your `.edu.au` email address. Cursor often provides free access to premium models (like GPT-4 and Claude 3.5 Sonnet) for verified students.
4. **Usage:** Press `Ctrl+K` (or `Cmd+K`) to generate code, or `Ctrl+L` (or `Cmd+L`) to chat with the AI about your codebase.
