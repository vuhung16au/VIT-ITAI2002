# Activity 8: Setup Tableau

**Objective:** Install and get familiar with Tableau for advanced data visualization and dashboard creation.

## Step 1: Choose Your Tableau Version

Tableau offers two main applications for individuals:
- **Tableau Public:** Completely free, but any work you save is published publicly to the web. Great for building a portfolio.
- **Tableau Desktop (Student License):** The full, professional version. It is free for students at accredited academic institutions.

*We highly recommend getting the free student license for Tableau Desktop for your coursework.*

## Step 2: Get Tableau Desktop (Free for Students)

1. **Apply for the License:** Go to the [Tableau for Students](https://www.tableau.com/academic/students) program page.
2. Click **Get Tableau for Free**.
3. Fill out the form. Ensure you use your `.edu.au` email address and provide any requested proof of enrollment.
4. Once verified, you will receive an email with a product key.

## Step 3: Install Tableau Desktop

1. **Download:** The verification email will contain a download link for Tableau Desktop (available for Windows and macOS).
2. **Install:** Run the installer and follow the on-screen prompts.
3. **Activate:** When you first launch the application, choose the option to activate with a product key and enter the key provided in your email.

## Alternative: Tableau Public

If you cannot wait for student verification, or prefer not to install the full desktop version immediately:
1. Go to [Tableau Public](https://public.tableau.com/en-us/s/download).
2. Enter your email and download the app (Windows and macOS).
3. Install and run. Remember that saving requires you to publish your workbook to the web.

## Step 4: Verify Installation
Open Tableau Desktop or Public. You should see the start screen with options to connect to data sources (like Excel, text files, or servers). If you see this screen, you are ready to start visualizing data!
