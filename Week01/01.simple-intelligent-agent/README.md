# Simple Intelligent Agent

This project implements a basic rule-based intelligent agent in Python (`HomeCleaningRobot`) that can perceive its environment and act accordingly based on a set of rules.

## Objective
To introduce students to the fundamental concepts of sensors, decision-making, and actuators in code.

## Structure
- `src/agent.py`: Contains the `HomeCleaningRobot` class.
- `src/environment.py`: Contains the `Environment` class.
- `src/main.py`: Contains the simulation loop.
- `src/test/`: Contains unit tests.
