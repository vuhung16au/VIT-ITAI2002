# Agent-Environment Interaction (Grid World)

## Objective
This project simulates a 2D environment using `numpy` and designs a Rational Agent capable of navigating this grid to reach a specific goal coordinate while avoiding basic obstacles. It reinforces the concepts of Rationality in intelligent agents.

## Features
- **GridEnvironment**: A 2D numpy-based world where states are represented by integers (0 for empty, 1 for obstacle, 2 for goal).
- **RationalAgent**: An agent that perceives its environment and makes logical decisions to reach a goal.
- Built following python best practices, utilizing `numpy` and tested using `pytest`.
