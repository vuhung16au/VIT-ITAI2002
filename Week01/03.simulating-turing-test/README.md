# Simulating Turing Test

This project is a basic conversational agent (chatbot) implemented in Python to explore the concepts behind the Turing Test. It demonstrates the difficulty of manually encoding human-like conversational responses by using simple pattern matching.

## Overview

The chatbot responds to a predefined set of patterns/keywords (e.g., greetings, asking about weather or name, telling a joke). If the input is not recognized, a fallback response is given.

This activity practically explores how string matching rules are limited compared to natural language understanding models.
