# Quickstart

This guide will help you set up and run the Simulating Turing Test chatbot.

## Prerequisites

- [uv](https://github.com/astral-sh/uv) must be installed.
- Python 3.9 or higher.

## Setup

Navigate to the project directory:

```bash
cd /Users/vuhung/00.Work/00.Workspace/VIT-ITAI2002/Week01/03.simulating-turing-test
```

## Running the Chatbot (Demo)

You can run the interactive chatbot directly using the Makefile:

```bash
make demo
```

## Running Tests

To run the unit tests, use:

```bash
make test
```

## Code Formatting and Linting

To check the code style:

```bash
make format
make lint
```
